ℹ️ About This Project
📚 Project Overview

University Merit List System is a full DSA project demonstrating core data structures and algorithms through a real-world application.

📌 Core DSA Used:

  • Merge Sort / Quick Sort / Heap Sort for ranking
  • Binary Search Tree for hierarchical storage
  • Doubly Linked List for student record chain
  • Hash Table for O(1) roll-number lookup
  • Queue (FIFO) for admission waiting list
  • Stack (LIFO) for undo operations
  • Binary Search / Linear Search / Jump Search
  • Arrays for base storage

📌 Features:

  • Add / Edit / Delete student records
  • Department-wise merit list generation
  • Real-time sort algorithm visualization
  • BST tree canvas drawing
  • Hash table with collision chaining
  • CSV export, merit list printing
  • Score distribution charts
  • Time/Space complexity reference
⚙️ Technical Details
📂 DATA STRUCTURE ARCHITECTURE
students[] → Array (base storage)
LinkedList → Doubly linked record chain
BST → Binary Search Tree by marks
HashMap → Roll → Student mapping
Queue → Admission waiting list (FIFO)
Stack → Operation history (LIFO)
MergeSort → Primary merit ranking
